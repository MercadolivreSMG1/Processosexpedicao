Gerar sessao.json Monitor de processos · Expedição SMG1

1. Copiar a sessão do Chrome (sem instalar nada)

  1. Abra envios.adminml.com/logistics/last-mile/monitoring/dispatch logado.
  2. Aperte F12 → aba Network (Rede). Aperte F5 para a lista encher.
  3. Clique com o botão direito na primeira linha da lista (o nome é dispatch) → Copy → Copy as cURL (bash). No Chrome em português: Copiar → Copiar como cURL (bash).
  4. Cole abaixo.

O que interessa é a linha -H 'cookie: …'. Nada sai deste computador: a conversão acontece no seu navegador e o arquivo é baixado direto.

Aguardando…

2. Colocar no GitHub

  1. Abra o sessao.json baixado no Bloco de Notas → Ctrl+A Ctrl+C.
  2. No repositório: Settings → Secrets and variables → Actions → New repository secret.
  3. Name: SESSAO_MELI · Secret: colar · Add secret.
  4. Aba Actions → robo-monitor-processos → Run workflow.

Quando o painel avisar que a sessão venceu, repita o passo 1 e atualize o secret.
